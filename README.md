# Clocky ⏰
### A Modern World Clock, Alarm & Stopwatch App

Clocky is a Flutter-based time management app designed to make everyday timekeeping simple, elegant, and convenient. It brings world clock functionality, alarms, and a stopwatch together in one clean mobile experience.

## ✨ Features

- 🌍 **World Clock** — View time across different cities and time zones.
- ⏰ **Alarm Clock** — Set and manage alarms for your daily routine.
- ⏱️ **Stopwatch** — Track elapsed time with a dedicated stopwatch interface.
- 🎨 **Clean UI** — A modern, intuitive interface designed for a smooth user experience.
- 📱 **Flutter Powered** — Built with Flutter for a responsive mobile experience.

## 🛠️ Tech Stack

- **Framework:** Flutter
- **Language:** Dart
- **Platform:** Android
- **IDE:** Visual Studio Code

## 🚀 Getting Started

Follow these steps to run Clocky locally.

### Prerequisites

- Flutter SDK
- Dart SDK (included with Flutter)
- Android Studio or Visual Studio Code
- An Android emulator or physical Android device

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/MrhRafi3/Clocky.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Clocky
   ```

3. Install dependencies:

   ```bash
   flutter pub get
   ```

4. Run the application:

   ```bash
   flutter run
   ```

## 📦 Build APK

To generate a release APK, run:

```bash
flutter build apk --release
```

The generated APK will be available at:

```text
build/app/outputs/flutter-apk/app-release.apk
```
